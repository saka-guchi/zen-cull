## 特徴

- 🎯 **AI 顔分析** — 顔検出、目の開き具合評価、シャープネス（ピント）スコアリング
- ⭐ **星評価** — EXIF 互換レーティング（0〜5）、キーボードのみで完結
- 🖼️ **シングル / グリッドビュー** — ワンキーで切り替え、素早い比較ワークフロー
- 📷 **RAW 対応** — Canon, Nikon, Sony, Panasonic, Leica, Fujifilm
- ⌨️ **キーボード中心設計** — マウス操作を最小限に抑え、腱鞘炎リスクを低減
- 🔒 **完全ローカル処理** — クラウドへのアップロードなし。写真はあなたの端末に留まります

### ヘッダーバー

| コントロール | 説明 | ショートカット |
|-------------|------|---------------|

## インストール

1. [Releases](https://github.com/saka-guchi/zen-cull/releases) ページを開く
2. 最新リリースから `ZenCull-Setup.exe` をダウンロード
3. インストーラーを実行（管理者権限不要）
4. スタートメニューまたはデスクトップショートカットから起動

アプリ起動時に Velopack により自動で最新版に更新されます。

## 使い方

1. **フォルダを開く** — `Ctrl+O` またはウィンドウにフォルダをドラッグ＆ドロップ
2. **写真を閲覧** — 矢印キーまたはサムネイルをクリック
3. **評価する** — `1`〜`5` で星を付与、`0` でクリア
4. **絞り込む** — ライブラリパネルの星フィルタで対象を絞り込み
5. **比較する** — `G` でグリッドビューに切り替え、並べて比較
6. **書き出す** — `Shift+E` で評価済み画像を書き出し
